# Extension icon

`icon.png` adapts the Blaster ray-gun from the [Lean-blaster repository's social
preview](https://github.com/input-output-hk/Lean-blaster). The unmodified source
image is kept here as `blaster-social-preview.png` for provenance; it is excluded
from the published VSIX. The square icon omits the wordmark and uses blue and
cyan colors so it remains legible at Marketplace icon size.
